# DrakeGym Environments

[DrakeGym](https://drake.mit.edu/pydrake/pydrake.gym.html) makes it easy to wrap Drake Systems in [Gymnasium](https://pypi.org/project/gymnasium/) environments. This is perhaps the simplest way to explore Drake simulations, and is the natural way to interface Drake simulations with machine learning libraries like [Stable Baselines 3](https://stable-baselines3.readthedocs.io/).

I've curated a number of manipulation-related environments in these notes, and will be adding more regularly.
